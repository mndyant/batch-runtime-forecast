# 素材・データ・依存の由来

## リポジトリに同梱しているもの

| 対象 | 確認できる由来・範囲 |
|---|---|
| data/demo/observed/・truth/・metadata/ | [生成スクリプト](../scripts/generate_demo.py)と固定seedに基づく合成データ。企業・顧客から取得した実績データではありません |
| 評価JSON/CSV | 同梱の観測・正解CSVを[評価器](../evaluation/)で採点した記録。未来の正解は通常の予測経路と分離 |
| docs/screenshots/ | 同梱アプリと合成データの操作画面。外部サイト・顧客システムの画面ではありません |
| HTML/CSS/JavaScript/SVG | 同梱ソースでUIとグラフを描画。外部CDNからのフォント・グラフ素材の取得や画像素材の埋込みは見つかっていません |
| 仕様・レビュー文書 | このアプリの開発資料。生成AIによる実装・レビュー補助を含みます。第三者の品質認証ではありません |

2026-10-08に取得済みGit履歴、追跡ファイル、生成器、APIのデータ読込経路を確認しました。これはファイルとコードから確認できる由来の記録です。勤務先等との契約、著作権の帰属、公開許可を技術的な検査だけで証明するものではありません。

## 第三者の依存ライブラリ

依存は requirements.txt / requirements-dev.txt でバージョン固定し、インストール時に取得します。仮想環境やライブラリ本体はリポジトリへ同梱していません。

| 主な依存 | インストール済み配布物のライセンス表記 | 用途 |
|---|---|---|
| [Flask](https://flask.palletsprojects.com/) | BSD-3-Clause | Web/API |
| [NumPy](https://numpy.org/) | BSD-3-Clause AND 0BSD AND MIT AND Zlib AND CC0-1.0 | 数値計算。配布物内の構成要素にも各表記あり |
| [pandas](https://pandas.pydata.org/) | BSD 3-Clause | CSV・日付・評価集計 |
| [pytest](https://docs.pytest.org/) | MIT | テスト |
| [Playwright](https://playwright.dev/python/) | Apache-2.0 | 任意のブラウザ検証 |

表記は2026-10-08の開発環境で配布物のメタデータから確認しています。これは主な直接依存の一覧で、すべての推移的依存やブラウザ同梱物のライセンス一覧ではありません。配布物を再梱包する際は、その配布物に含まれるLICENSE・NOTICEも確認してください。本リポジトリの[利用条件](../RIGHTS.md)は第三者ライブラリの許諾を変更しません。

## 利用者が取り込むCSV

利用者提供CSVの由来・公開権限はアプリでは判定しません。アプリはCSVを計算中のメモリで使用し、ファイルやDBへ保存する実装はありません。出力JSONには入力履歴が含まれるため、結果の共有時にも内容を確認してください。公開デモではサーバーへの送信が発生するため、同梱サンプルなど非機密のデータで試してください。
