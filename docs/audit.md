# 監査と実行記録

## 実施結果

- 自動テスト：38 passed、102 subtests passed（3.48秒、Python3.14.3、pytest9.1.1）。
- 最終採点：120ケース、失敗0。探索：30ケース、失敗0。モデル設定の調整なし。
- 凍結対象469ファイルを最終評価の前後で照合。コード、プロトコル、データ、依存指定、API、監査テストを含む。文書の評価レポート・画像・表示用HTML/CSS/JSは結果追記・画面修正のため対象外。
- 実ブラウザ：1280pxと390px、18項目合格。意図した不正CSVのHTTP400を除き、JavaScript/コンソールエラーなし。[詳細JSON](verification/ui.json)

## テストで確認した対策

| 対策 | 確認 |
|---|---|
| 起点以前の3列のみをモデルへ渡す | spyで列・行・学習最終日を照合 |
| 未来実績を変更・追加しても予測を変えない | 同一起点の全候補forecastとparametersの一致 |
| 監査を手法選択に使わない | development_end固定で未来改変後もscores・選択が一致 |
| 標準化は過去のみ | ridgeのmean/stdを手計算と照合 |
| 再帰は予測値のみ | 予測期間を延長しても共通prefixが一致 |
| 全候補を同一条件で比較 | fold境界、件数・時間MAE/RMSE、全候補行数、日付一致 |
| 基準0の改善率を捏造しない | N/Aを確認 |
| 締切と最終着手を日付込みで計算 | 日跨ぎ、時刻一致、秒切上げ、24時間超、境界を手計算 |
| 最終正解を予測前に渡さない | 全3候補の確定後にtruthを読む順序をspyで照合 |
| 凍結・上書き防止 | ハッシュ不一致で拒否、実行ロックで再実行を拒否 |
| 失敗を消さない | 読込失敗ケースがreportに残ることを確認 |
| 入力・予測の異常を黙って直さない | 0/減少/重複/欠損/不正日付/上限/不正設定を検証 |

これらは実装した経路のテストであり、リークや過学習があらゆる条件で存在しないとの証明ではない。同じ生成器から作るデータには共通の構造がある。実データでの外部検証は未実施。

## UI確認

初期表示、2つのグラフの件数/時間切替、最新予測と過去比較の独立性、TXT/CSV/JSON内容、1/7/30日、処理中の操作制限、設定変更後の古い結果保存防止、6シナリオ、サンプルCSV保存、アップロード・解除、不正CSVからの復帰、初期化、翌日締切、倍率、評価詳細、スマホの表内スクロールを確認。

実ブラウザで初期化ボタンとform.resetの名前衝突を発見して修正。faviconの404も修正後に再確認。スクリーンショットを視認し、PCは入力左・結果右、スマホは縦配置で、本文が画面外へ横にはみ出さず、長い表は内部スクロールすることを確認。
